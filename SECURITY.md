# Security policy

## Supported versions

Security fixes are applied to the latest release published on `main`.

## Reporting a vulnerability

Report security issues privately:

https://github.com/elongvieira/lockrnotes/security/advisories/new

Do not open a public issue, pull request, or discussion for a suspected vulnerability. Please include the version, the platform, and a description that is enough to reproduce the problem without including passwords, tokens, recovery material, or note contents.

We will acknowledge the report, investigate it, and coordinate a fix before any public disclosure.
